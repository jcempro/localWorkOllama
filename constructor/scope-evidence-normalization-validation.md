# SW-HYBRID/T8H — validação da normalização do vínculo

Em19/10/2026, execução exclusivamente do supervisor, C=8, sem Worker/subagente. Causa: schema MCP aplicava trim/seleção de campos, mas calculador vinculava texto bruto; consumidor direto também podia serializar campos não vinculados. Correção usa o mesmo normalizador source/content no hash e no contexto efetivo, sem mutar pedido, colapsar whitespace interno ou alterar limite/permissão/regime.

Gates executados com exit0: sincronização44 artefatos; test-hybrid-policy.mts; test-hybrid-mcp.mts; test-execution-contract.mjs; sintaxe worker-core e diff sem erro. Política preserva casos anteriores 0/5/7/10, incerteza, scope expandido, patentes/checkpoints; novos casos demonstram equivalência das bordas/schema, rejeição de conteúdo efetivo alterado e tipos inválidos. MCP real em fixture chega à guarda de conversa arquivada e não cria jobs; alteração substantiva continua recusada por hash. Runtime com modelo simulado demonstrou contexto sem campo extra e com espaços internos preservados. Nenhuma inferência real, envio de chat, UI ou alteração no Git do alvo autorizado; HEAD/status antes/depois iguais. Avisos experimentais do Node não são falhas.

Fonte TypeScript canônica e artefatos são gerados pelo sync oficial; RCF/howto permanecem coerentes. Não houve mudança no schema do servidor, algoritmo SHA-256, criticidade, modo/esforço, autorizações ou scripts da governança upstream. A correção implementa a projeção normalizada já contratada, não uma dispensa de vínculo.
